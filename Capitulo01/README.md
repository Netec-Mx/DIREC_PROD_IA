# Laboratorio 1 – Diseño y evaluación inicial de una iniciativa de Inteligencia Artificial

**Duración:** 45 minutos  
**Modalidad:** Individual o por equipos  
**Herramientas:** Presentación del curso, documento de trabajo y cualquier herramienta de IA generativa.

## Objetivo

Integrar los aprendizajes del capítulo para estructurar una iniciativa de IA, evaluando su oportunidad de negocio, datos, MVP y criterios de calidad antes de decidir cómo avanzar.

## Planteamiento

Trabaja sobre una sola iniciativa de IA durante todo el laboratorio. Puedes utilizar una oportunidad real de tu organización o un caso de estudio. El propósito no es diseñar la solución completa, sino reunir evidencia suficiente para decidir si está preparada para avanzar.

Si ya trabajaste una iniciativa durante las actividades del Capítulo 1, continúa con la misma.

## Ruta de trabajo

| Tiempo | Paso | Resultado |
|---|---|---|
| 5 min | 1. Definir la oportunidad | Necesidad + valor esperado |
| 8 min | 2. Evaluar los datos | Preparación + acciones prioritarias |
| 10 min | 3. Definir el MVP | Hipótesis + alcance mínimo + indicador |
| 8 min | 4. Establecer calidad | Criterios + controles |
| 8 min | 5. Revisar riesgos | Riesgos + controles iniciales |
| 6 min | 6. Tomar la decisión | Continuar, ajustar o replantear |

## Paso 1 – Definir la oportunidad de negocio

**Consulta:** Lección 1.1.  
**Haz:** Describe la necesidad u oportunidad, quién se beneficia, qué resultado quieres cambiar y por qué la IA podría aportar una capacidad diferencial.  
**Registra:** necesidad de negocio, usuario o área beneficiada, tipo de IA y valor esperado.  
**Comprueba:** ¿podría resolverse de forma más simple con reglas o automatización convencional?

## Paso 2 – Evaluar la preparación de los datos

**Consulta:** Lección 1.2.  
**Haz:** Evalúa disponibilidad, accesibilidad, calidad, gobernanza y preparación para IA. Clasifica cada dimensión como **No preparado**, **Requiere trabajo** o **Suficiente para experimentar**.  
**Registra:** datos necesarios, fuentes, nivel de preparación y tres acciones prioritarias.  
**Comprueba:** ¿existe alguna carencia de datos que impida comenzar el experimento?

## Paso 3 – Definir el MVP y la evidencia

**Consulta:** Lección 1.3.  
**Haz:** Formula la hipótesis de beneficio y define el alcance mínimo que permita comprobarla. Conserva únicamente las características indispensables para aprender.  
**Registra:** hipótesis, Job to Be Done, Must Have, indicador principal y evidencia esperada.  
**Comprueba:** ¿el MVP permite aprender sin construir la solución completa?

## Paso 4 – Definir calidad y controles

**Consulta:** Lección 1.4.  
**Haz:** Define de tres a cinco criterios observables para evaluar la calidad del MVP. Incluye al menos un criterio relacionado con confianza o control.  
**Registra:** criterio, forma de evaluación, límite aceptable y responsable.  
**Comprueba:** ¿puedes distinguir una respuesta útil y confiable de una que no debería aceptarse?

## Paso 5 – Identificar riesgos y controles iniciales

**Consulta:** Lecciones 1.1, 1.2 y 1.4.  
**Haz:** Selecciona los riesgos más relevantes y define un control inicial para cada uno.  
**Registra:** riesgo, impacto, control y responsable.  
**Comprueba:** ¿algún riesgo debe resolverse antes de realizar el MVP?

## Paso 6 – Tomar una decisión

Revisa toda la evidencia y selecciona una decisión: **Continuar, Ajustar o Replantear**.

Registra:
- decisión;
- dos evidencias que la sustentan;
- siguiente acción prioritaria.

## Plantilla de trabajo

Completa como mínimo:

1. Necesidad de negocio.
2. Usuario o área beneficiada.
3. Tipo de IA y capacidad esperada.
4. Valor esperado.
5. Datos necesarios y nivel de preparación.
6. Tres acciones prioritarias sobre datos.
7. Hipótesis de beneficio.
8. Job to Be Done.
9. Alcance del MVP / Must Have.
10. Indicador principal.
11. Criterios de calidad.
12. Riesgos y controles.
13. Decisión final: Continuar / Ajustar / Replantear.
14. Evidencia que sustenta la decisión.
15. Siguiente acción prioritaria.

## Resultados esperados

Al finalizar habrás definido:

- la **necesidad de negocio**;
- el **valor esperado**;
- la preparación de **datos**;
- el **MVP**;
- los **criterios de calidad**;
- los principales **riesgos y controles**;
- la decisión sobre cómo **continuar la iniciativa**.

**Resultado integrado:** Necesidad → Datos → MVP → Calidad → Evidencia → Decisión

## Entregable

Entrega una ficha de **una a dos páginas** con los elementos de la plantilla. No es necesario desarrollar código ni construir un modelo de IA.
