# Laboratorio 2 - Diseño, planificación y validación de una solución de Inteligencia Artificial

## Objetivo
Integrar los aprendizajes del capítulo para **diseñar, planificar y validar una solución de IA**, estableciendo mecanismos para su mejora continua.

**Duración:** 45 minutos  
**Modalidad:** Individual o en equipos  
**Herramientas:** Material del curso, documento de trabajo y una herramienta de IA generativa de elección.

## Punto de partida
Continúa con la misma iniciativa de IA trabajada en el Laboratorio 1. Utiliza como insumos la necesidad de negocio, los datos identificados, el MVP, los criterios de calidad y la decisión inicial.

## Ruta
**Arquitectura → Requisitos → Backlog → Roadmap → Experimento → Mejora**

## Paso 1. Diseña la arquitectura - 8 min
Consulta la **Lección 2.1**.
1. Selecciona el patrón: Prompt, RAG, Workflow o Agente.
2. Representa el flujo principal: Usuario → Aplicación → Orquestación/Prompt → Modelo → Datos/Herramientas → Respuesta → Evaluación.
3. Identifica APIs, servicios o fuentes necesarias.
4. Define el nivel de autonomía y dónde se requiere intervención humana.

**Registra:** patrón, componentes, integraciones y autonomía.

## Paso 2. Define requisitos verificables - 9 min
Consulta la **Lección 2.2**.
1. Selecciona una Persona y una funcionalidad relevante.
2. Redacta una Historia de Usuario.
3. Define 3 criterios de aceptación verificables.
4. Convierte 2 criterios en escenarios **Dado que / Cuando / Entonces**: uno esperado y uno alternativo o de excepción.

**Registra:** Persona, Historia, criterios y escenarios.

## Paso 3. Prioriza y construye el roadmap - 10 min
Consulta la **Lección 2.3**.
1. Selecciona tres características del Backlog.
2. Estima valor, criticidad temporal, reducción de riesgo/oportunidad y tamaño del trabajo con una escala relativa común.
3. Calcula Costo de la Demora y WSJF y ordénalas.
4. Ubícalas en **Ahora / Después / Futuro** e identifica una condición que podría cambiar el orden.

**Registra:** Backlog priorizado y roadmap.

## Paso 4. Diseña el experimento y la mejora - 10 min
Consulta la **Lección 2.4**.
1. Define la línea base y el resultado que debe mejorar.
2. Selecciona el enfoque de adaptación: prompts, RAG, ajuste fino, entrenamiento propio o combinación.
3. Define 3 métricas o criterios.
4. Diseña 3 escenarios: normal, límite y adverso/inesperado.
5. Define qué evidencia permitiría implementar, ajustar o continuar experimentando.

**Registra:** línea base, enfoque, experimento, métricas, pruebas y decisión.

## Paso 5. Integra la decisión - 8 min
Comprueba que arquitectura, requisitos, prioridades y experimento apunten al mismo resultado de negocio. Identifica el ajuste principal antes de la siguiente iteración.

**Decisión final:** continuar con el plan, ajustar arquitectura/requisitos/prioridad o realizar un nuevo experimento.

## Resultados esperados
- Visión y arquitectura coherentes.
- Características, habilitadores e integraciones identificados.
- Requisitos y criterios de aceptación verificables.
- Backlog priorizado.
- Roadmap inicial.
- Experimentos y métricas.
- Retroalimentación y mejora continua.

**Resultado integrado:** Visión → Arquitectura → Requisitos → Backlog → Roadmap → Experimentación → Evaluación → Mejora continua.

## Entregable
Un único documento o tablero con las decisiones del laboratorio, suficientemente claro para comprender **qué se construirá primero, cómo se comprobará y qué evidencia orientará la siguiente iteración**.
